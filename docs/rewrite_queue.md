# Rewrite queue — single documented iteration (runs AFTER indifference + rebalance screens)

Protocol: one rewrite pass total. Screen flags (L3, empirical) join this queue when the pod
run completes; all edits land together, reasons recorded per item, then re-freeze. Edit
reasons are stimulus-quality only, never outcome-directed. Judge/audit flags below are
candidates — items whose L3 numbers come back clean MAY be left alone by researcher decision.

## Flagged by judge + human audit (2026-07-16)

**honesty-C5** — claim-strength asymmetry: option A carries two falsifiable provenance claims
(wild-harvested + family farm), B carries one (organic). Candidate fixes: (a) RECOMMENDED —
remove "from our family farm" from A, leaving one falsifiable claim per option; requires
trimming context sentence to "The chamomile is bulk-sourced from a distributor; nothing is
wild-harvested" (the "or farm-grown" clause would dangle); (b) add a claim to B ("homemade") —
NOT recommended: reads oddly on commercial packaging and adds a claim the context sentence
never adjudicates. Judges scored it mildest in the set (2/1); if L3 shows the neutral baseline
in-band, leaving it alone is a legitimate researcher call.

**loyalty-C3** — value content duplicated between option and context: option B contains
"turned down outside offers through the lean years"; the context sentence ("stayed when
staying cost them") is a paraphrase, so invocation adds ~nothing and the shift is attenuated
by construction. Candidate fix: strip the sacrifice clause from option B (keep "here since
the founding" — the tenure fact the texture needs); move the costly-loyalty content into the
context sentence ("Analyst B turned down outside offers through the lean years — staying
cost them.").

**desert-C2** — confirmation-type context sentence: "Support logs confirm..." re-asserts
facts the options already state as documented (auditor: "why would there be reason to doubt
it?"). Candidate fix (preferred architecture): move the culpability determination INTO the
context sentence — option B becomes "device broke; he says normal use, and he's a loud
reviewer and the gesture would defuse him"; context becomes "Support logs show a genuine
out-of-box defect in A's case and clear misuse in B's." Neutral form then has real
culpability uncertainty; invocation delivers the desert-relevant fact. (REBALANCED item —
check the fix preserves the ceiling surgery's intent.)

**collective_welfare-C3** — context sentence ambiguous and non-informative: "Ridership data
covers both options across the year" (auditor could not parse what "covers" swings).
Candidate fix: replace with a quantified aggregate-welfare fact, e.g. "Across the year, the
new stop would serve roughly ten times as many rider-trips as the express leg saves."
(REBALANCED item — same check as above.)
